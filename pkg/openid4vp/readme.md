# Go implementation of OpenID4VP 1.0

This package targets [OpenID for Verifiable Presentations 1.0](https://openid.net/specs/openid-4-verifiable-presentations-1_0.html) (Final, 9 July 2025). Older draft numbers (draft 21, draft 24, draft 29, ...) may still appear in historical comments or referenced upstream code; they describe intermediate drafts that were merged into the frozen 1.0 text this package tracks.
